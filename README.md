# Scientific Calculator App 🧮

A clean, modern, and responsive Scientific Calculator built using **Flutter and Dart**, featuring advanced mathematical operations, dynamic themes, and live currency conversion.

## ✨ Features

- **Scientific Calculations:** Trigonometric functions, logarithms, and standard arithmetic operations.
- **Dynamic Themes:** Seamless Light and Dark mode switching.
- **Live Currency Conversion:** Real-time currency exchange rates.
- **Responsive UI:** Clean and adaptable interface for mobile screens.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Programming Language:** Dart

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Iqra-55/Calculator.git
```

**2. Navigate to project directory**

```bash
cd Calculator
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
