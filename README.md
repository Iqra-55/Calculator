# Scientific Calculator App 🧮

A clean, responsive Scientific Calculator built using Flutter and Dart.

## 📱 Features
- **Scientific Calculations**: Trigonometric functions, logarithms, and standard arithmetic operations.
- **Dynamic Themes**: Built-in Light and Dark mode switching.
- **Live Currency Conversion**: Real-time currency exchange rates integrated.
- **Responsive Layout**: Adaptable layout for mobile screens.

## 🛠️ Tech Stack
- **Framework**: Flutter
- **Language**: Dart

##  🚀 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/Iqra-55/Calculator.git
```

2.Navigate to project directory:

```bash
cd Calculator
```

3.Install dependencies:

```bash
flutter pub get
```
4.Run the app:

```bash

flutter run
```
